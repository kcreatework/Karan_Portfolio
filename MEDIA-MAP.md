# MEDIA-MAP.md

Every image (and one GIF) placeholder on the site, organised by project/blog folder, plus the About page.
Each row = one real dummy file already sitting in `images/<folder>/` today.
**To update: open the file, replace it with your real photo (or GIF), keep the exact same filename, hard-refresh the browser.** No code or `data.js` editing needed.

Every placeholder file now maps to exactly **one** spot on the site — no filename is reused across two different locations anymore, so replacing one image never changes a second, unrelated spot.

See `IMAGES-GUIDE.md` for the full how-to (crop guidance, troubleshooting, adding new slots).
